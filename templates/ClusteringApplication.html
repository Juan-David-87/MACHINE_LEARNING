Patient Clustering Application (K-Means)

Problem Context

Unsupervised machine learning allows us to discover hidden patterns in medical data. This module uses the K-Means algorithm to group patients based on their response to a specific drug treatment.

Dataset Details

  • Source: Real Drug Dataset
  • Total Records: >1000 Patients
  • Features Used: Dose (mg) and Improvement Score
