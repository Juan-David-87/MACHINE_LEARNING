K-Means Clustering Analysis - Complete Manual Exercise

1. Introduction

This report explains the complete manual execution of the K-Means Clustering Algorithm using a dataset of 100 records with two numerical variables:

  • X₁ = Age (years)
  • X₂ = Income ($k) (thousands of dollars)

Since the dataset has no labels, K-Means is used as an unsupervised learning algorithm to discover hidden patterns and natural groups.

The objective is to separate customers into 3 clusters according to similarity in age and income.

2. Dataset Explanation

The dataset contains customers from young adults to older adults, with low, medium and high income ranges. A positive correlation is expected: people with higher age usually tend to have higher income.

3. K-Means Methodology

  1. Select number of clusters: K = 3
  2. Choose initial centroids manually
  3. Calculate Euclidean distance from each point to each centroid
  4. Assign each point to nearest centroid
  5. Recalculate centroids using arithmetic mean of assigned points
  6. Repeat until convergence (minimal centroid movement)
Euclidean Distance Formula: d(P,C)= √[(X₁p-X₁c)² + (X₂p-X₂c)²]

8. Detailed Distance Calculations

Example 1: Young customer to C1 (Low income cluster)

Point (25, 32) to Centroid C1 (22, 28):

d = √[(25-22)² + (32-28)²] = √(3² + 4²) = √(9 + 16) = √25 = 5

Since this is the shortest distance, the point belongs to Cluster 1.

Point (45, 56) to each centroid:

Point (64, 125) to Centroid C3 (60.6, 116.9):

d = √[(64-60.6)² + (125-116.9)²] = √(3.4² + 8.1²) = √(11.56 + 65.61) = √77.17 = 8.78
