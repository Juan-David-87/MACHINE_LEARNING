Unsupervised Machine Learning

Basic Concepts of Clustering

Understand how clustering works and how K-Means helps discover hidden patterns in data without labeled outputs.

What is Unsupervised Learning?

Unsupervised learning is a type of machine learning where the model works with data that has no predefined labels. Its goal is to discover hidden structures, patterns, or relationships within the dataset automatically.

What is Clustering?

Clustering is an unsupervised learning technique used to group similar data points together. Objects inside the same cluster are more similar to each other than to those in other clusters.

What is K-Means?

K-Means is one of the most popular clustering algorithms. It divides data into K groups (clusters), where each observation belongs to the cluster with the nearest center.

Centroids

A centroid is the center point of a cluster. It represents the average position of all points inside that group. During training, centroids are updated repeatedly until the best cluster structure is found.

Distance Metrics (Euclidean Distance)

K-Means commonly uses Euclidean Distance to measure similarity between points and centroids. The smaller the distance, the more likely a point belongs to that cluster.

Formula:
d = √((x₂ - x₁)² + (y₂ - y₁))²

Iterative Process

K-Means works through repetition:

  • Select K initial centroids
  • Assign each point to the nearest centroid
  • Recalculate centroids
  • Repeat until clusters stop changing

Variance and Convergence

K-Means tries to minimize variance inside each cluster, meaning points should be as close as possible to their centroid. The algorithm converges when centroid positions no longer change significantly.

Real-World Applications

Clustering is used in many industries:

  • Customer segmentation in marketing
  • Medical image analysis
  • Fraud detection
  • Document classification
  • Recommendation systems
